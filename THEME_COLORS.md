Your portfolio now uses a cohesive **Warm Earthy Dark Theme** that complements the natural, architectural aesthetic of your homepage garden image.

## Color Palette

### Primary Colors

```css
/* Background - Warm Dark Browns */
--warm-dark: #1a1612;           /* Main background */
--deep-brown: #0f0d0a;          /* Gradient accent */
--card-brown: #2a2218;          /* Card backgrounds */

/* Accent - Sandstone Gold */
--sandstone-gold: #b8956a;      /* Primary accent color */
--warm-beige: #d4c4a8;          /* Light accent text */
--soft-cream: #f5f1eb;          /* Bright text */
```

### Gradient Orbs

```css
/* Forest Green (from garden) */

--grass-green: #4a9d5f;

/* Terracotta/Sandstone (from architecture) */
```

## Design Philosophy

**Cohesion**: All pages now share the same warm, natural color palette extracted from your homepage image.

**Progression**: The journey from the bright, natural homepage to the warm dark interior pages feels like moving from an outdoor garden into a cozy, sophisticated indoor space.

**Professionalism**: Dark theme maintains the modern, professional look expected in developer portfolios while adding warmth and personality.

**Natural Feel**: Colors inspired by nature (forest greens, sandstone, terracotta) create a grounded, authentic aesthetic.

## Usage Tips

### Adding New Pages
When creating About, Contact, or other pages, use:
- Background: `linear-gradient(135deg, #1a1612 0%, #0f0d0a 100%)`
- Accent color: `#b8956a` (sandstone gold)
- Card backgrounds: `rgba(42, 34, 24, 0.6)`
- Borders: `rgba(184, 149, 106, 0.15)`

### Hover States
- Background: Increase sandstone opacity
- Border: `#b8956a`
- Shadow: `rgba(184, 149, 106, 0.3)`

### Text Colors
- Primary: `#f5f1eb` (soft cream)
- Secondary: `rgba(255, 255, 255, 0.7)` (translucent white)
- Accent: `#d4c4a8` (warm beige)
